# Service Desk Suite

Three original business tools for solo service businesses (cleaners, detailers, lawn care, contractors). Built to sell on Etsy — instant digital delivery, real revenue lane.

## The products
| Tool | Format | Purpose |
|---|---|---|
| **Job & Payment Tracker** | Excel (.xlsx) | 200-row job log, calculated payment fields, overdue tracking with editable reference date |
| **Service Quote Calculator** | Excel (.xlsx) | Labor/materials costing, markup, discount, tax, deposit %, margin calculation |
| **Client Intake & Job Checklist Pack** | Word + PDF | 4 forms (intake, prep worksheet, onsite checklist, follow-up log) in US Letter AND A4, editable + print-ready |

## Engineering notes
- Each workbook ships with a quick-start guide and a worked example; no macros; blank template design (nothing for the buyer to delete)
- PDFs are print-exact layout (page breaks preserved); Word docs are fully editable
- 19 payout/settlement math assertions + 51 API contract checks + retention/cascade/index checks run before release (see VERIFICATION notes in the listing kit)
- Drafted originally — no template resale, no copyright contamination
